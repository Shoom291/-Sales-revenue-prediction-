# Прогнозирование выручки от продаж (Sales Revenue Prediction)

## О проекте
Данный проект посвящен анализу данных о продажах и построению модели машинного обучения для прогнозирования общей выручки (`total_revenue`) на основе исторических данных. Решение может быть использовано для планирования закупок, управления запасами и оценки эффективности рекламных кампаний.

## Задачи проекта
- Загрузка и первичный анализ данных (EDA);
- Очистка и предобработка данных (кодирование категориальных признаков, стандартизация);
- Построение и сравнение нескольких моделей регрессии;
- Интерпретация результатов через анализ важности признаков.

## Стек технологий
- Python 3
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn (LinearRegression, RandomForestRegressor, GradientBoostingRegressor)

## Данные
Используется датасет `time_series_dataset.csv`, содержащий информацию о продажах:
- `datetime` — дата и время продажи;
- `product_category` — категория товара;
- `region` — регион продажи;
- `priority` — приоритет заказа;
- `units_sold` — количество проданных единиц;
- `price_per_unit` — цена за единицу;
- `total_revenue` — общая выручка (целевая переменная);
- `defect_rate_pct` — процент брака.

## Результаты
В ходе исследования были обучены три модели. Наилучшие результаты показала модель **Random Forest**:
- **MAE:** ~52.7
- **RMSE:** ~79.0
- **R²:** ~0.988
